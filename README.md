# Predictive Analytics for Academic Success (PAAS)

The **Predictive Analytics for Academic Success (PAAS)** project is a web-based application that analyzes student transcript and performance data to identify early signs of academic decline.  
Developed as a high school summer camp project, PAAS was inspired by the common problem of **senioritis** — a sudden downward trend in student performance during the final year of high school.  

This tool aims to help teachers, parents, and students **detect grade drops early** so interventions can be made before long-term academic success is compromised.

---

## ✨ Features
- **Grade Tracking** – Uses past transcript and grade data to identify performance trends.  
- **Attendance Integration** – Considers attendance data alongside grades for more accurate predictions.  
- **Drop Detection** – Flags when a student begins showing signs of decline.  
- **Senioritis Focus** – Specifically designed to model sudden performance drops in the senior year of high school.  
- **Teacher/Parent Alerts** – Provides a foundation for systems where educators and guardians can be notified of risk.
